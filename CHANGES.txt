Notch Island 4.0.0 — обновления сами, за секунды

- Новые версии Notch Island теперь приходят с GitHub сами: приложение раз в 3 часа проверяет, скачивает готовую сборку в фоне и показывает «Обновить» с описанием изменений. Скачивать архивы вручную больше не нужно.
- Установка обновления — несколько секунд: сборка уже сделана и проверена на серверах GitHub, на Mac она только подписывается его постоянной подписью (разрешения сохраняются) и подменяется.
- Настройки → Основные → «Обновления с GitHub» — можно выключить. Архив, положенный в «Загрузки», по-прежнему подхватывается.

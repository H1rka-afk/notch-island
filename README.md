# Notch Island

A Dynamic Island for MacBooks with a notch: Now Playing, charging, AirPods,
Focus, timers, file shelf with AirDrop, lock-screen player and widgets.

* **Install:** download `Notch-Island-v….zip` from [Releases](../../releases),
  unpack it and open «Установить Notch Island.command».
* **Updates:** the app finds new releases here by itself and installs them in
  a few seconds (Settings → Основные → «Обновления с GitHub»).
* Every push to `main` with a new version in `Source/Info.plist` is built on
  GitHub's Macs (`.github/workflows/release.yml`), tested and released.

Notes for each version: `CHANGES.txt`; full history: «ПРОЧТИ МЕНЯ.txt».

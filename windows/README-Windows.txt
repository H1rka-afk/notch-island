Ovira для Windows 11 — первая версия (0.1.0)

Как запустить
- Распакуй архив в любую папку (например, «Документы\Ovira») и открой Ovira.exe.
- Windows может показать «Windows защитила компьютер»: нажми «Подробнее» → «Выполнить в любом случае». Так бывает с любой программой без платной цифровой подписи.
- Островок появится вверху экрана по центру, значок Ovira — в области уведомлений справа на панели задач (может прятаться под стрелкой «^»). Нажми на него — откроются настройки.

Что уже есть
- Островок вверху экрана с пружинными анимациями, как на Mac.
- Медиаплеер для всего, что играет в Windows: Spotify, Яндекс Музыка, браузер и другие. Обложка, название, полоски в такт музыке, перемотка, кнопки, выбор устройства вывода звука.
- Открытие по нажатию или при наведении, отклик на курсор.
- Баннеры: громкость, зарядка, низкий заряд, смена устройства звука.
- Прячется в полноэкранных играх, видео и презентациях.
- Настройки: запуск вместе с Windows, размер островка, сброс.

Чего пока нет
- Такси и доставка, живые активности, таймер, отдых для глаз, полка — в следующих версиях.
- Своего экрана блокировки на Windows не будет: система не пускает программы на экран входа.

Если что-то не так
- Настройки → Основные → «Папка настроек»: там errors.log — пришли его.
